# Читаем со вкусом

Отдельный статический раздел MyWorld: `https://space.lpsflow.ru/book/`.
Исходники в `public/`, сборка через `build.mjs`, включение в общую сборку через `scripts/sync-client-sites.mjs`.

Перенесена текущая редакция flat-book-v3 без изменений текста, семи разделов, логотипа и визуалов. Карта содержания — CONTENT-MAP.md, решения и проверка редакции — REFINEMENT-V3.md.

Переписка, голосовые сообщения, личные исходные документы и служебные материалы не включены. Регистрация пока не подключена; существующая честная маркировка и отключённые действия сохранены. Аналитика не добавлена. Индексация отключена до отдельного согласования.

Git push доставляет исходники в репозиторий, но сам по себе не подтверждает обновление публичного сервера.
