# ЭСТЕ Kids в My World

Это копия текущей версии `../../../EsteKids`, перенесённая без изменения текстов, страниц, фотографий, видео и документов. Соответствие прямое: `index.html`, `app.js`, `source-content.js`, CSS и `public/` сохранены; изменены пути для размещения под `/st-kids/`. Удалена одна ссылка CSS на отсутствующий ещё в исходном проекте декоративный файл `clover-paper.webp`.

`npm run sync:clinic` из корня My World публикует эту папку в `public/st-kids/`. Демонстрационная форма клиники, как и в исходном проекте, не отправляет заявки; пользователю показывается соответствующее сообщение и телефон.
