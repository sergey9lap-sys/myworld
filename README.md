# myworld — Личный архив Сергея

Первая версия личного мира Сергея. Next.js / React / TypeScript / GSAP.

`pnpm install` → `pnpm dev`, адрес http://localhost:4190.
`pnpm build` — проверка и сборка, `pnpm start` — просмотр сборки.

Объекты, координаты, подписи и медиа меняются в `lib/world.ts`. Файлы находятся в `public/media`.
Стикеры реагируют на нажатие. Проекты и фотографии приближаются. Запись проекта загружается только после нажатия «Смотреть запись». Barcelona Vision раскрывает четыре экрана, каждый можно приблизить. Esc возвращает к предыдущему масштабу; Home — к началу.

Черновые заметки можно заменить на авторские. Карта ограничена 12000 × 8000; фактические композиции сгруппированы в центре. Издалека доступен обзор кнопкой карты. Перемещение камеры обновляет только transform; объекты далеко за экраном скрыты и исключены из фокуса.

Ничего не опубликовано, старые проекты не изменены.
