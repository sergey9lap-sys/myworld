# Личный мир Сергея

Экспериментальный личный сайт. Свободное исследование фотографий, сайтов, стикеров и платформы Barcelona Vision. Рабочее название «Можно поближе»; название можно заменить.

Формат утверждён: ограниченный мир 12000 × 8000, DOM + CSS transforms, Next.js / React / TypeScript, GSAP. Не обычный вертикальный лендинг. Пять областей вокруг стартовой композиции. Тёплая бумажная поверхность, графитовая типографика, реальные фото и скриншоты, разнообразные объекты.

Нужно: pan, pinch и zoom относительно курсора, мягкие границы, инерция, переходы к областям, возврат к прежней камере, навигация с клавиатуры и reduced motion. Просмотр проектов внутри мира, без модального окна. Барселона раскрывает дополнительную композицию экранов.

Записи и снимки принадлежат пользовательскому архиву. Новые заметки — редакционные черновики для замены авторскими мыслями, без выдуманных биографических заявлений. Никакой отправки форм или публикации без запроса. Старые сайты независимы.
