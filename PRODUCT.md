# Личный мир Сергея

Экспериментальный личный сайт. Свободное исследование фотографий, сайтов, стикеров и платформы Barcelona Vision. Рабочее название «Можно поближе»; название можно заменить.

Формат утверждён: ограниченный мир 12000 × 8000, DOM + CSS transforms, Next.js / React / TypeScript, GSAP. Не обычный вертикальный лендинг. Пять областей вокруг стартовой композиции. Тёплая бумажная поверхность, графитовая типографика, реальные фото и скриншоты, разнообразные объекты.

Нужно: pan, pinch и zoom относительно курсора, мягкие границы, инерция, переходы к областям, возврат к прежней камере, навигация с клавиатуры и reduced motion. Просмотр проектов внутри мира, без модального окна. Барселона раскрывает дополнительную композицию экранов.

Записи и снимки принадлежат пользовательскому архиву. Новые заметки — редакционные черновики для замены авторскими мыслями, без выдуманных биографических заявлений. Никакой отправки форм или публикации без запроса. Старые сайты независимы.

## Рекомендации Сергею — 06.10.2026

По прямому запросу Сергея добавлена независимая страница `/work/` в мире MyWorld: сайты, Telegram-боты и мини-приложения; знакомство → работа из архива → заявка. Главная доска, её содержание и поведение не заменяются лендингом. Новый текст — стартовая редакционная версия для дальнейшего согласования; без выдуманных кейсов, цен и гарантий.

Персональные ссылки `/r/CODE` предназначены для клиентов, рекомендующих услуги Сергея, в том числе Ильмиры. Сервер связывает первую действующую рекомендацию на устройстве с заявкой, хранит данные в закрытой SQLite. Кабинет `/partners/` доступен только владельцу: создание ссылок, открытия, заявки, ручные статусы. Открытия не означают уникальных людей или покупки. Условий комиссии, автоматической оплаты, бонусов, выплат, каталога экспертов и Telegram-бота в этом этапе нет.

Локальная версия и синтетические проверки не являются доказательством публикации на сервере. Доступ владельца, данные и секрет подписи не публикуются в Git. Фактическое уведомление об обработке заявки не заменяет согласованные юридические документы. Развёртывание и публичный домен проверяются отдельно; границы и команды находятся в `referral/README.md`.
